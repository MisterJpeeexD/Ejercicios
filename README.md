---

## 📋 Contenido del Repositorio

El código está organizado modularmente para cubrir los pilares fundamentales del lenguaje:

| Módulo | Descripción Técnica |
| :--- | :--- |
| **Variables & Operadores** | Asignación, tipos de datos y operaciones lógicas/aritméticas. |
| **Estructuras de Datos** | Manejo de Listas (Arrays) y Objetos compuestos. |
| **Flujo de Control** | Implementación de Bucles (`for`, `while`) y estructuras condicionales. |
| **Casos de Uso** | Menús interactivos optimizados mediante estructuras `switch`. |
| **Modularidad** | Declaración y ejecución de Funciones eficientes. |
| **Interactividad** | Captura manual de datos en entorno local mediante `prompt`. |
